# Turing Machine — a shareable board

A browser board for the deduction game *Turing Machine* (Le Scorpion Masqué), built so a
group who each own the physical game can play the same puzzle while apart.

**Play it:** open the GitHub Pages site for this repository.

One person builds a machine and shares a short code; everyone else opens the same link and
gets the identical cards, the identical hidden settings and the identical answer, while
keeping their own notes. Everything runs in the browser — one self-contained HTML file, no
accounts, no server, no network calls, nothing sent anywhere.

You can also paste a puzzle straight off turingmachine.info, including the Daily Challenge,
and play the exact puzzle the site set.

This repository holds only the built page. It is generated output, replaced wholesale on
each publish, so it has no meaningful history.
